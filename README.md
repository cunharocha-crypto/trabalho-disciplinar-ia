[Ciência de Dados] Tratamento com Pandas (df.drop) e Normalização Min-Max (fit_transform)Na prática da ciência de dados, enviar dados brutos diretamente para um modelo de IA — seja no supercomputador da Streamberry ou nos algoritmos de recomendação das redes sociais — é um erro grave por dois motivos técnicos essenciais:   Remoção de Colunas Sensíveis e Inúteis (df.drop):
Quando recebemos uma tabela de dados, ela traz colunas que não ajudam a prever comportamentos (como "Nome", "CPF", "Nº da Conta" ou fotos da pessoa). Além de violar leis de privacidade como a LGPD, manter essas informações faz a máquina gastar memória desnecessária e induz a IA a criar padrões falsos (ruído). Quando utilizo o comando df.drop(columns=['Nome', 'CPF']), estou a descartar essas colunas para anonimizar a base de dados e manter apenas o que realmente importa para os cálculos.

Normalização Min-Max (fit_transform):
O computador não compreende o significado das coisas no mundo real; ele avalia apenas o tamanho dos números. Se o dataset contiver a idade de uma pessoa (ex: 17 a 50 anos) e a sua renda ou tempo de ecrã (ex: 3.500), a máquina vai achar que o valor 3.500 é milhares de vezes mais importante só porque é um número maior. A normalização Min-Max resolve este problema ao ajustar todos os valores para uma escala única entre $0.0$ e $1.0$. Dessa forma, o algoritmo consegue comparar a variação de cada dado sem viés de escala.   2.
